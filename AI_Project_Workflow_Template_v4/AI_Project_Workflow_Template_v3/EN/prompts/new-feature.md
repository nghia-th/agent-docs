# Prompt — New Full-Stack Feature

Implement a new feature end-to-end.

Before coding:
1. Read `AGENTS.md`.
2. Inspect existing frontend/backend implementation.
3. Read relevant business rules, data model and API contracts.
4. Identify affected screens, modules, entities, endpoints and tests.
5. State assumptions and gaps.

Plan:
- business behavior
- API changes
- database changes/migration
- backend implementation
- frontend implementation
- tests
- verification

Do not edit until the plan is clear if the project's workflow requires confirmation.

After implementation, run relevant tests/builds and report exact results.
