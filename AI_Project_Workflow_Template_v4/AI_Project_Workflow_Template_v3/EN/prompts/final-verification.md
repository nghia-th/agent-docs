# Prompt — Final Verification

Before declaring the task complete:
1. Inspect all changed files.
2. Run targeted backend tests.
3. Run targeted frontend tests.
4. Run integration/security tests when relevant.
5. Run build/typecheck/lint when available.
6. Check database migration/schema status.
7. Check API contract consistency.
8. Check authorization/ownership.
9. Check no unrelated files changed.
10. Report exact commands and outcomes.

If something could not be verified, say so explicitly.
