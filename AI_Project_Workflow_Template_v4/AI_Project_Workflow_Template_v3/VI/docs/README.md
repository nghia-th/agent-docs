# Template Inventory / Danh sách template

- `docs/backend/`: backend architecture, domain, security, database, validation, errors, API
- `docs/backend/modules/`: business-module templates
- `docs/frontend/`: frontend documentation entry
- `prompts/`: reusable AI workflows
- `EN/`: English version
