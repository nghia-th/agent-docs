# UI Workflows

Mô tả workflow end-to-end:
1. Screen bắt đầu
2. User action
3. Frontend state transition
4. API request
5. Backend validation/authorization
6. Database effect
7. API response
8. UI result/error
9. Loading/empty
10. Refresh/navigation

Dùng tài liệu này để đồng bộ frontend với backend contract.
