# Backend API Contracts

Đây là tài liệu backend-facing bổ sung cho `docs/API.md`.

Mỗi endpoint ghi:
- controller/module
- request DTO
- validation
- service operation
- authorization
- response DTO
- status code
- error contract
- pagination
- idempotency
- audit/logging nếu có

Phải đồng bộ với tài liệu API phía frontend.
