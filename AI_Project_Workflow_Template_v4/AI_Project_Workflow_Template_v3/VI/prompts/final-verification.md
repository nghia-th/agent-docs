# Prompt — Final Verification

Trước khi kết luận hoàn thành:
1. Inspect toàn bộ file đã đổi.
2. Chạy backend tests liên quan.
3. Chạy frontend tests liên quan.
4. Chạy integration/security tests nếu cần.
5. Chạy build/typecheck/lint nếu có.
6. Kiểm tra migration/schema.
7. Kiểm tra API contract consistency.
8. Kiểm tra authorization/ownership.
9. Kiểm tra không đổi file ngoài phạm vi.
10. Báo đúng command và kết quả.

Nếu có thứ chưa verify được phải nói rõ.
