# Prompt — Feature Full-Stack Mới

Implement feature mới end-to-end.

Trước khi code:
1. Đọc `AGENTS.md`.
2. Inspect frontend/backend hiện tại.
3. Đọc business rules, data model và API contract liên quan.
4. Xác định screen, module, entity, endpoint và test bị ảnh hưởng.
5. Nêu assumption/gap.

Plan:
- business behavior
- API
- database/migration
- backend
- frontend
- tests
- verification

Nếu workflow yêu cầu confirmation thì không edit trước khi plan rõ ràng.

Sau implementation phải chạy test/build liên quan và báo kết quả thực tế.
