# Prompt — Investigate a Bug

Ban đầu không edit code.

Read the referenced bug record and relevant project/feature documents. Trace the issue across UI → API → backend → database where applicable.

Trả về:
- reproduction assessment
- evidence
- root-cause candidates
- most likely root cause
- affected layers
- regression test plan
- minimal safe fix plan

Chỉ edit sau khi root cause và plan đã rõ.
