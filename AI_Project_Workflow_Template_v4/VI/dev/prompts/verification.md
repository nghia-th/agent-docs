# Prompt — Development Verification

Verify task/feature hiện tại.

Check:
- business rules
- API contract
- authentication/authorization/ownership
- database/migration
- frontend behavior
- error handling
- tests
- build/typecheck/lint
- unrelated changes

Báo command và kết quả chính xác. Không nói thành công nếu chưa thực sự verify.
