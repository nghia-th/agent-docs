# dev/ — Development Workspace

`dev/` is the working area for concrete development work. It does not contain production source code and does not replace stable system documentation under `docs/`.

## Levels
1. `dev/features/` — complete feature workspaces.
2. `dev/tasks/` — small, executable work items.
3. `dev/bugs/` — defect investigation and resolution.

## Supporting records
- `dev/decisions/` — explicitly agreed decisions.
- `dev/prompts/` — prompts tailored to the development workflow.

## Relationship
`docs/` = stable system knowledge.
`dev/features/` = current feature workspace.
`dev/tasks/` = executable work.
`dev/bugs/` = defect investigation.
`dev/decisions/` = recorded decisions.

Keep temporary notes and scratch material out of stable `docs/` unless they become authoritative.
