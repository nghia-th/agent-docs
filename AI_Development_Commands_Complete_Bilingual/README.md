# AI Development Commands — Complete Bilingual Pack

Đây là bộ command độc lập để điều khiển AI coding agent theo workflow Full-Stack.

- `VI/commands/` — câu lệnh tiếng Việt để copy/paste.
- `EN/commands/` — phiên bản tiếng Anh.
- `00_CORE` — IDEA → DESIGN → APPROVAL → TASKS.
- `01_FEATURE` — lifecycle của feature.
- `02_TASK` — thực thi task.
- `03_BUG` — bug workflow.
- `04_DATABASE` — database workflow.
- `04_API` — API workflow.
- `05_SECURITY` — security workflow.
- `06_CODE` — code review/refactor/debug.
- `07_TESTING` — test workflow.
- `08_RELEASE` — final verification/release.
- `09_SPECIAL` — project analysis/impact/decision records.

## Recommended operating model

`AGENTS.md` + `docs/` = stable project knowledge.

`dev/` = active development records.

This command pack = instructions that tell the AI how to operate on that knowledge.

**Recommended flow:**
`IDEA → ANALYZE → DESIGN → REVIEW → APPROVE → TASK → IMPLEMENT → TEST → VERIFY`
