# ANALYZE IDEA — Deep Analysis

Read ý tưởng hiện tại and design proposal if applicable.

Do not code.

Hãy phân tích sâu according to các góc:
- Product/business
- UX workflow
- Domain model
- Backend architecture
- API contract
- Database
- Security
- Authorization/ownership
- Error handling
- Performance/scalability
- Testing
- Backward compatibility

Tìm:
- ambiguity
- contradiction
- missing rule
- hidden dependency
- risky assumption
- unnecessary complexity

Không tự giải quyết các vấn đề business chưa được anh quyết định.

Cuối cùng đưa ra:
1. Confirmed decisions
2. Open questions
3. Recommended options
4. Impact matrix
5. Design recommendation
