# READ FIRST

Before any command in this pack:

1. Read `AGENTS.md`.
2. Read the relevant `docs/` files.
3. Read relevant `dev/` feature/task/bug/decision records.
4. Inspect the existing implementation before proposing code changes.
5. Treat the backend as the final authority for authorization, validation, ownership, lifecycle and data integrity.
6. Never turn an assumption into a business rule without confirmation.
7. Never claim tests/builds passed unless they actually ran and passed.
8. Preserve existing architecture and conventions unless a change is explicitly approved.
