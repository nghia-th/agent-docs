# DESIGN — Create the Feature Design

Dựa trên IDEA and các quyết định has được xác nhận.

Do not write source code.

Create/update:

`dev/features/<feature-name>/`
- `README.md`
- `REQUIREMENTS.md`
- `API.md`
- `DATA.md`
- `UI.md`
- `TEST_PLAN.md`
- `TASKS.md`

Check and chỉ cập nhật tài liệu ổn định in `docs/` khi feature làm thay đổi kiến thức hệ thống.

Thiết kế must bao phủ:
- requirements
- business rules
- domain/data
- API
- frontend
- backend
- database/migration
- security
- ownership
- error handling
- tests
- dependencies

Đánh dấu clear CONFIRMED / ASSUMPTION / OPEN QUESTION.

Do not edit source code.
Wait for review.
