# CHANGE REQUEST — Analyze a Design Change

Anh muốn thay đổi:

[THAY ĐỔI CỦA ANH]

Chưa sửa source code.

Trace impact trên:
- Requirements
- Business Rules
- Domain
- Data Model
- Database/migration
- API
- Backend
- Frontend
- Security
- Authorization/ownership
- Error handling
- Reports/integrations
- Tests
- Existing tasks

Distinguish:
- Direct impact
- Indirect impact
- No impact

Propose tài liệu need cập nhật.

Do not code.
Không tự quyết định business behavior mới.
Wait for confirmation of the impact/design.
