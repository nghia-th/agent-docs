# APPROVE DESIGN

Design của feature đã được anh review và APPROVED.

Hãy:
1. Ghi nhận trạng thái APPROVED trong feature record.
2. Kiểm tra lại assumptions/open questions.
3. Nếu còn OPEN QUESTION ảnh hưởng implementation, dừng và nêu rõ.
4. Finalize TASKS.md theo dependency.
5. Không viết source code trong command này.

Sau khi hoàn tất, báo:
- Feature status
- Number of tasks
- Task dependency order
- Remaining risks
