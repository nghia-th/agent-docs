# DESIGN — Create the Feature Design

Dựa trên IDEA và các quyết định đã được xác nhận.

Chưa viết source code.

Tạo/cập nhật:

`dev/features/<feature-name>/`
- `README.md`
- `REQUIREMENTS.md`
- `API.md`
- `DATA.md`
- `UI.md`
- `TEST_PLAN.md`
- `TASKS.md`

Kiểm tra và chỉ cập nhật tài liệu ổn định trong `docs/` khi feature làm thay đổi kiến thức hệ thống.

Thiết kế phải bao phủ:
- requirements
- business rules
- domain/data
- API
- frontend
- backend
- database/migration
- security
- ownership
- error handling
- tests
- dependencies

Đánh dấu rõ CONFIRMED / ASSUMPTION / OPEN QUESTION.

Chưa edit source code.
Chờ anh review.
